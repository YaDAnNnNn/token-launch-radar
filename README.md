A token launch radar that ranks protocols which record no token yet in a sealed DefiLlama snapshot by an implied launch value calibrated on the protocols whose tokens already trade, each row with a concrete farm plan.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input path/to/snapshot.json
```
